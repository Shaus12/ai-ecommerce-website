## 01 — 一道很窄的闸口

Theme: 一整间公司自己在跑，只有三件事必须挤过一道很窄的闸口
Structure: 概念隐喻
Core idea: 二十多只小黑各自忙着干活，谁也不用请示；但花钱、对外发布、签字这三件事被收拢成三条路，全都必须挤过同一道窄闸口，闸口的插销握在一只人手里。
Composition: 画面右半边散着七八只小黑，各做各的荒诞工作：搬黑箱子、拉线、写字、举牌、蹲着记录，彼此不相干。画面中间偏左立着一道又高又窄的闸口，只容一只小黑侧身通过。三条橙色路径从右边的小黑群里分别抽出来，汇向这道闸口前排队，三只小黑抱着东西排在闸口前等着。闸口顶上有一根插销，一只手从画面左上伸进来捏住插销——只画这只手，不画人。闸口左边是一大片完全空白的纸面。
Elements: 又高又窄的闸口 / 三条橙色路径与排队的小黑 / 捏着插销的一只手 / 右边各自忙碌互不相干的小黑群
Labels: 花钱 / 对外发布 / 签字 / 其他自己跑 / 你只管这根插销

## 02 — 别拿大机器磨小活

Theme: 按活的重量分配脑子，贵的脑子只留给最沉的那几块

Core idea: 活分轻重。沉的活交给又大又贵的那台机器，一天只喂进去两三块；轻的杂活倒进最小最便宜的那台，哗啦一大堆。省钱不是少干活，是别拿大机器磨小活。
Composition: 小黑站在一个手做的分拣台前，台面朝三个方向各伸出一条短滑道，通向三台一大一中一小的手绘机器。小黑正双手抱起一块很沉的黑方块，身体被压得歪着，要放进最大那台；最大的机器口上只躺着两三块。中间那台不大不小，进来几块。最小那台机器口上堆着一大堆小碎块，快要满出来。三台机器的大小对比要非常明显。右边留一整块空白。
Elements: 分拣台与三条短滑道 / 一大一中一小三台手绘机器 / 被压歪的小黑抱着沉方块 / 最小机器口堆满的小碎块
Labels: 最沉的判断 / 日常杂活 / 贵 / 便宜 / 别拿大机器磨小活
